# Learning Path Across the Educational Repositories

This file provides navigation across educational/reference repositories. It does not replace, merge, archive, or redirect any repository.

`decision-intelligence-in-action` is intentionally excluded because it is a separate book repository rather than part of this learning-path index.

## 1. Mathematical and optimization foundations

- `mathematics-for-machine-learning` — mathematical background for ML.
- `integer-programming-for-operations-research` — integer programming, relaxations, branch-and-bound, cuts, formulation quality, and exact optimization concepts.
- `sequential-decision-analytics` — bandits, dynamic programming, MDPs, reinforcement learning, and sequential decision structure.
- `sequential-decision-analytics-policy-classes` — PFA, CFA, VFA, and DLA policy meta-classes on a common sequential decision problem.

## 2. Bayesian and uncertainty-aware learning for optimization

Turkish and English repositories are intentionally kept as separate educational resources.

- `bayesian-optimization-endustri-muhendisligi` — Turkish Bayesian optimization guide for Industrial Engineering.
- `bayesian-optimization-industrial-engineering` — English Bayesian optimization guide for Industrial Engineering.
- `bayesci-sinir-aglari-optimizasyon-rehberi` — Turkish guide to Bayesian neural networks in optimization and OR.
- `bayesian-neural-networks-optimization-guide` — English guide to Bayesian neural networks in optimization and OR.

These language-specific pairs are preserved independently by design.

## 3. Graph learning for OR and optimization

Turkish and English broad guides are intentionally kept separate.

- `gnn-ile-yoneylem-arastirmasi-ve-optimizasyon` — Turkish GNN-for-OR guide.
- `gnn-for-industrial-engineering-and-or-optimization` — English GNN-for-OR guide.
- `graphsage-cora-node-classification` — GraphSAGE architecture fundamentals.
- `graph-attention-network-cora` — GAT architecture fundamentals.

Suggested progression:

`GraphSAGE/GAT basics -> graph representation for OR -> GNN-guided optimization`.

- `differentiable-optimization-pytorch` — tutorial introduction to differentiating through optimization layers.
- `differentiable-optimization-portfolio` — applied convex differentiable optimization.
- `differentiable-black-box-supplier-selection-pytorch` — differentiation through discrete black-box optimization.

## 6. Domain-specific learning references

- `machine-learning-in-finance-course` — ML in finance.
- `industry-4.0-lab` — curated applied Industry 4.0 projects using industrial data and cyber-physical context.

## Learning-path principle

Educational repositories remain self-contained so that each topic can be studied independently. Repetition across languages, datasets, or controlled benchmark problems is acceptable when it supports a different learning objective.

The portfolio should distinguish between:

- **learning/reference repositories** — explain a concept or method;
- **research sandboxes** — compare algorithms or methodological variants;
- **application repositories** — solve a concrete industrial/OR problem.

This distinction is more useful than reducing repository count for its own sake.
