# Learning Path

## 1. Mathematical prerequisites

`mathematics-for-machine-learning`

Study linear algebra, calculus, probability/statistics, and the compact optimization examples first.

## 2. Optimization for training ML models

`optimization_for_machine_learning/`

Use this module to study conditioning, convergence, stochastic methods, adaptive optimizers, second-order methods, proximal methods, diagnostics, and controlled benchmarks.

## 3. Optimization as a differentiable component

- `differentiable-optimization-pytorch`
- `differentiable-optimization-portfolio`

## 4. Prediction for downstream decisions

- `decision-focused-learning-spo`
- `predict-then-optimize-production-planning-spo-plus-pytorch`

## 5. Expensive black-box optimization

- `bayesian-optimization-industrial-engineering`

## 6. Learning algorithms for combinatorial optimization

- `neural-combinatorial-optimization-tsp-attention-model-pytorch`
- `gnn-guided-generalized-assignment-variable-fixing-pytorch`
- `learning-to-branch-mip-gnn-scip-pytorch`

## 7. Sequential decision optimization

- `sequential-decision-analytics`
- `reinforcement-learning-job-shop-scheduling-pytorch`

The intended progression is foundations -> optimization for ML -> optimization layers/decision-focused learning -> learned combinatorial and solver methods.
