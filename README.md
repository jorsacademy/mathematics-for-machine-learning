# Mathematics for Machine Learning

A collection of concise, verified Python implementations that accompany core mathematical topics used in machine learning.

The code in this repository is intended for educational and non-commercial use only.

## Topics

- Linear algebra
- Calculus
- Probability and statistics
- Optimization

## Repository structure

```text
linear_algebra/
calculus/
probability_statistics/
optimization/
```

Each example focuses on mathematical correctness and clarity rather than framework-specific abstractions.
